# StockTracker
### 1단계:콘솔 CLI
- 관심 종목 등록
- 무료 주식 API 사용
- 자바로 일정 주기마다 가격 체크하는 스케줄러 직접 구현(`ScheduledExecutorService` 활용)
- 조건 충족 식 콘솔 출력 또는 로컬 알림 (이메일 발송 API 연동?)

### CS요소
- 스레드/동시성(여러 종목을 동시에 폴링하려면?)
- 옵저버 패턴(가격 변화를 "구독"하는 구조 - 객체지향 연습)
- Rate limiting(API호출 제한 처리 - 큐/토큰 버킷 알고리즘)

### 2단계: 파일 -> DB 마이그레이션
- 처음엔 JSON/텍스트 파일로 관심 종목 저장
- SQLite -> MySQL/PostgreSQL로 전환
- 가격 히스토리를 시계열로 저장하면서 인덱싱, 쿼리 최적화 경험

### 3단계: Spring Boot로 웹 서비스화
- REST API로 종목 등록/조회/삭제(CRUD)
- `@Scheduled`로 주기적 가격 체크(Spring의 스케줄링 기능과 직접 구현한 것 비교하며 배우기)
- 알림은 이메일(JavaMailSender) 또는 웹소켓으로 실시간 푸시까지 확장 가능

### 4단계: 프론트엔드
- 간단한 대시보드로 관심 종목/알람 현황 시각화
